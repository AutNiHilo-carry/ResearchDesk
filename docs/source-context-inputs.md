# 来源上下文：离线候选验证输入

为[被拒修订](portfolio-citation-repair-20261123.md)中的版本引用与建议事实前提问题，新增独立入口`researchdesk.source_context`。它只导出两套模型输入，不加载凭证、不评分、不修改修订选择；默认引用验证器及历史门槛不变。

## 要解决的问题与合同区别

原验证器要求每条摘录独立支持整行事实。摘录不含版本，而冻结来源正文标题含版本时，原合同仍可能判partial。不能将“来源包含”偷偷改成“摘录已支持”。新入口把两种问题明确分开：

| 输入 | 支持依据 | 用途 |
| --- | --- | --- |
| quote-only-v2 | 该引用的原摘录 | 现有合同，payload和指纹与verification.prepare一致 |
| source-context-candidate-v1 | 原摘录＋同一绑定来源的完整正文 | 显式候选合同，观察来源版本／条件能否得到支持 |

候选合同没有把标题、URL、文件名或Ledger原claim当作行为证明。来源正文中的版本标题只限定文档范围，不能推导该版本拥有正文未说明的能力；上下文不能覆盖明确矛盾，不能借用另一个来源，也不能替未引用的事实补引用。全部资料都是不可信数据，其中指令不得执行。

两套输入保留同一正文、单元和引用ID，原Evidence不重写、不扩充为新的同ID摘录。候选输入追加source_id和去重的来源正文、location、内容hash；先复用原证据完整性校验，再检查来源映射ID。引用或来源篡改、未知引用均拒绝候选导出。无关来源和可变title不进入候选支持依据。

来源全文增加输入量和潜在干扰，所以限制完整序列化候选payload不超过60000字符；超限拒绝，不静默截断。原单元数量上限60仍由现有prepare检查。这个字符限额不包含system prompt，不是Token／金额上限。当前不支持网页重新获取，不声称来源权威性已认证。

## 建议和混合句

候选提示明确保留“任一可核查事实前提都需判断”的规则，包括建议、推断和“资料不足”之前的事实断言；纯建议仍可判非事实。输入准备不按关键词过滤行、不生成factual标签。原v2本身已有相关规则，本次候选措辞并不证明能改善模型判定；需要后续独立标注和控制实验。

候选输入不接入repair、task_eval或delivery的验收。即使未来候选得分变高，也可能来自支持依据和事实分母变化，不能覆盖旧分数或称为正文质量提升。本轮没有进行这种评分，更没有人工准确率结果。

## 使用

对已完成运行，输出必须是原运行目录之外的新目录：

```powershell
.\.venv\Scripts\python.exe -m researchdesk.source_context runs/<RunID> --output runs/source-context-inputs/<新目录>
```

输出两套JSON（prompt、payload及各自hash）、manifest.json和README.md。成功退出0；输入不完整、篡改、超限或输出已存在退出1；输出在原运行目录内部为参数错误退出2。复用load_run的只读快照读取，不写入原SQLite、报告或评分。没有execute／自动付费步骤；导出成功不表示材料语义正确。

## 已验证范围

机制测试覆盖旧输入逐项相同、同一来源去重、无引用行保留、来源正文／位置／ID／摘录篡改拒绝、无关来源和title不影响输入、超限不创建目录、禁止输出到原目录、离线导出和拒绝覆盖。测试验证绑定与接线，不验证模型能否正确区分事实。

真实材料的离线导出保存在`runs/source-context-inputs/20261123-a/`，原文件hash前后一致：

| 正文 | 原payload字符 | 候选payload字符 |
| --- | --- | --- |
| PostgreSQL原稿 | 1845 | 2603 |
| Stripe API v1原稿 | 1567 | 2229 |
| PostgreSQL被拒候选 | 1736 | 2494 |

这些是含路径等字段的序列化字符数，不是Token。第三份通过build_inputs API导出，先核对candidate.md与已保存candidate_sha256；普通CLI始终读取load_run选中的正文，不自动改用被拒候选。三份均禁用网络与dotenv加载后导出，新增API0、未重评分、人工审核pending；本地输入不提交仓库。

历史冻结执行计划绑定源代码版本。新增模块后，旧计划的再次付费执行可能按设计被代码hash校验拒绝；不要更新旧hash绕过检查。历史报告仍可只读导出。真正的下一步是冻结独立候选评测计划，分开控制“增加来源上下文”和“事实性提示措辞”，与独立参考意见比较，不用小样本自动晋升策略。

后续已完成[2×2首轮真实实验](context-factorial-result-20261123.md)：12次评分、25286返回Token，未观察到可归因的稳定收益；保留候选与默认合同差异，原分数不改。
