# 条件作用域与引用范围回归

2026-11-16。新增19个结构参考案例，对v1/v2/v3分别核查，共57组版本/案例组合。参考是工程结构约定，不是事实正确性或模型判断gold，独立人工复核仍pending。

## 新发现与版本边界

v2能识别有限的“只有一个”资源数量表达，但“只有一个连接可用时”“只有一个线程完成后”“只有一个进程退出前”也会被放开拆分，可能切断后续动作的条件依赖。

因此新增显式启用的clause-spans-v3：沿用v2数量例外，但若“只有”所在的同一逗号/分号/句号前片段以“时/后/前”结束，则保留整行条件保护。v1、v2行为与既有实验均不修改，默认仍v1；granularity_probe新增可选v3，不切换默认工作流。

该规则保守且有限，不能解析所有时间或条件表达；“同一时间只有一个写入者”仍是数量陈述，不因“时间”一词而整行禁拆。句末时间限定也可能只是描述而不是条件，故v3尚不晋升默认策略。

## 引用范围

案例覆盖显式引用、无引用片段、行末候选池、引号/代码中的分号及未知数量/名词。所有版本必须精确覆盖原文，不丢失引用集合，策略版本写入输出。

仅在最后片段出现引用时，现有策略将其标记为parent_final_candidate_pool，前片段direct_citations仍为空。这是候选范围，不是语义支持。若前面另有显式引用，分号前无引用事实保持无引用，不把后半句的引用补给它。

初版测试将单一行末引用误期望为显式作用域，验证时发现它按既有合同属于候选池；已将这两种结构拆成独立案例，分别检查citations、direct_citations与citation_binding，未放宽生产绑定规则。
