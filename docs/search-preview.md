# 搜索工具上下文预览

真实网页探测使用10次模型请求、累计100,457 Token。请求次数上限不能控制单次上下文大小；搜索工具原先将每个已保存摘要的content完整放进ToolMessage，搜索结果和后续历史会增加输入负担。

新增 search-return-v1 的preview选项，只改变搜索返回的呈现。默认full保持旧返回结构和默认提示词；preview不自动晋升，不代表已验证节省Token或提高质量。

```powershell
.\.venv\Scripts\researchdesk.exe "研究问题" --search-context preview --max-model-calls 10 --max-provider-requests 4
.\.venv\Scripts\python.exe -m researchdesk.workflow "研究问题" --search-context preview --max-model-calls 10 --max-provider-requests 4 --tool-retries 0
```

此选项适用于可检索网页的运行，不改变工具权限；local-only不能选择preview。它与本地导入资料的full/catalog策略、报告写作v1/v2和语义判定v1/v2是独立选项。

## 保存与呈现

搜索供应商响应仍经过原有校验；全部结果校验成功后，按现有每条12000字符上限入库，Source ID和sha256仍由URL及已保存content计算。没有删除或改写已有快照，也没有因为预览变短改变证据ID规则。

preview响应保留ID、标题、URL、种类、时间和哈希，以preview返回前600字符，并附saved_snippet_chars和preview_truncated。它不返回content字段，明确标记search_snippet_preview，避免把局部预览冒充完整来源。600字符只限制每条preview，标题/URL等元数据仍有成本；短摘要也可能因标记字段而略增返回量。

read_source仍尝试通过Tavily提取网页正文并保存独立快照，最多24000字符；未改为“免费看完整搜索摘要”的新工具。正文返回不裁成600字符，提取仍占外部请求额度，可能失败。预览因此可能隐藏关键条件、增加正文读取或使证据不足，必须通过独立任务实验检查。短摘要不是网页全文，预览中有逐字片段也不自动证明结论。

## 恢复语义

新运行保存search_context_policy，数据库记录同一策略的版本、mode、预览长度和说明哈希。ResearchTools在查工具缓存之前校验绑定；已有调用后不能给未标版本的旧运行重新贴preview标签，未知模型reservation也视为历史。不得在恢复参数中提供替换模式。

已完成报告的CLI快捷返回也进行只读策略检查，防止把旧full报告重标成preview而绕过绑定。旧运行未保存策略时保持full，不补造历史；历史full缺少记录可只读返回，preview缺少记录则拒绝。工作流计划也锁定该策略，修订分支继承。

ToolExecutor持久化的是当时实际返回的full或preview结果；模式绑定保证恢复不会混用两种收据。修改返回语义时应升级策略版本，修改说明或预览长度也会使不匹配的旧绑定拒绝继续。版本哈希不是授权签名，不能防止有意同时改数据库和文件的管理员。

## 验证

离线检查涵盖：默认返回形状及基础提示词不变，预览仍保留12000字符快照，原ID/哈希不变，正文读取与证据校验不变，同一次调用恢复不再次请求，切换/移除/伪造策略拒绝，历史调用禁止重标，实际Agent提示词使用预览说明，以及工作流转发和恢复覆盖拒绝。

还可对历史已保存的搜索收据做纯离线返回量测量：把同一批快照分别序列化为full/preview，比较字符数。它不重跑模型、不改旧运行，不代表整段上下文有界、Token比例相同、费用下降或报告质量提升；实际工具顺序、正文读取和缓存成本都可能变化。

本阶段先实现与测量，未改变默认full，也未追加模型或Tavily调用。下一阶段如做真实对照，应冻结问题、资料/检索条件、模型、提示词、预算和评分器，并保留失败及工具调用差异。

## 2026-11-12 离线测量记录

对上次SQLite网页任务3次成功搜索的原始收据做同快照渲染，full合计23,472字符，preview合计15,375字符，减少约34.50%。源ID、已保存内容和旧运行文件哈希均未改变，新增API请求0次。

这只统计三份序列化搜索工具返回，不含正文读取、其他模型上下文或后续工具调用，不可据此宣称Token/金额下降34.50%或质量提升。产物见本地 `runs/search-context-measurements/sqlite-saved-20261112/summary.md`。完整离线回归321项通过；此离线测量本身不是模型质量对照。

## 后续真实网页先导（2026-11-12）

同一公开WAL问题分别运行full/preview，每组最多8次模型、4次Tavily。实际累计11次模型、8次Tavily、70,458 Token，无补跑。full研究阶段因最终输出使用全角证据括号而格式校验失败，质量未评估；preview进入待复核，引用指标未达标，尾部预算保护阻止了无验证额度的继续生成。

研究生成Token分别33,214/32,212，但完整尝试Token为33,214/37,244；两组结束阶段、模型调用次数和实际检索资料均不同，不能将总量差异归因于预览。默认仍保持full。明确发现的接口问题是全角引用标记，原失败输出已只读恢复并另存，未改原记录或补做评分。详细产物见本地 `runs/search-context-pilots/live-wal-20261112/findings.md`；候选策略的普遍质量/成本收益仍未证明。
