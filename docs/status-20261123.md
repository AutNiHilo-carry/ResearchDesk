## 交付入口

```powershell
python -m researchdesk.delivery create <完整评分的批次> --dataset <原任务集.json> --output <新的交付目录>
python -m researchdesk.delivery verify <交付目录>
```

打开index.md可查看逐题报告、模型／应用门槛、保存预算与Token声明，并进入证据台账、逐行质量和空白复核表。验包不依赖原批次路径，检查文件hash、跨文件锚点、指标与门槛复算、可读材料一致性；最后发布manifest.json，保留不完整目录与原文件保护语义。详见[交付包合同](delivery-v1.md)。

create的0／3沿用原应用门槛通过／未通过或未知；verify的0仅表示交付完整性和已保存标签一致，不能替代引用语义、研究正确性或人工验收。报告源数据与机器标签属于待检查内容，整个包不算独立盲审。统计不重测事件、不发放预算，未知保留null，费用与Recovery Rate未测。
