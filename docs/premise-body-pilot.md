## 冻结与执行

原问题、200字以内等原附加要求、原候选全文、全部现有来源/证据，以及上一轮完整声明附件一起冻结。资料为既有两份项目编写的官方文档局部摘记，没有新增搜索或外部工具。输入中的声明仍为待核查数据，不是已通过的人工标签。

实验提示词要求事实单独成行并绑定完整支持的证据，联合结论显式关联实际依赖的多个证据；不重复事实稀释指标，不把推断/建议当事实豁免，不添加用户未要求的制作过程元信息，不把幂等键等建议写成已成立的保证。它是单题实验指令，没有新增或晋升生产 report_policy 版本。

固定 deepseek-flash、temperature=0、timeout=90秒、max_retries=0；修订输出上限4096 Token，判定各8192 Token。顺序在执行前固定：一次修订 → 原被拒稿重新判分 → 新稿判分 → 新稿业务检查，最多4次请求。新稿若结构无效则停止依赖检查；即使引用判分失败，仍检查业务要求保留情况。不因失败补跑。

两份正文使用相同的 report-quote-v2 提示词、完整逐行切分和严格逐条摘录支持口径；新稿业务检查复用原三条 rubric 与 research-task-rubric-v1。来源、问题、提示词及相关源码哈希均保存在本地冻结计划。
