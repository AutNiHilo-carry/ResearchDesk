# SQLite WAL：选型摘记

这是 ResearchDesk 根据官方页面编写的局部中文摘记，不是网页完整快照。核对日期：2026-11-16。页面未固定 SQLite 发布版本，不能据此证明所有版本行为相同。

SQLite 文档将 rollback journal 描述为默认方式，WAL 是可选择的另一种日志模式。
WAL 允许读取和写入并行，但仍然同一时刻只有一个写者。
使用 WAL 数据库的进程须在同一台主机；该模式不支持跨主机共享网络文件系统中的数据库文件。
这些事实没有给出特定业务的吞吐量或延迟保证。
