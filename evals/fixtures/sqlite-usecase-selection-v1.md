# SQLite 使用场景：选型摘记

这是 ResearchDesk 根据官方页面编写的局部中文摘记，不是网页完整快照。核对日期：2026-11-16。页面未固定 SQLite 发布版本。

SQLite 面向应用和设备的本地数据存储，也用于桌面应用文件格式；客户端/服务器数据库面向共享数据管理等需求。
若很多写者需要同时写入且不能排队，文档建议考虑客户端/服务器数据库。
若执行 SQL 的应用与数据库分处不同机器，应优先考虑客户端/服务器数据库。
远程用户访问同一主机上的应用服务器，由该服务器访问本机 SQLite，与多台主机直接共享同一个数据库文件不同。
这些选型提示不构成任何特定负载的性能测量。
